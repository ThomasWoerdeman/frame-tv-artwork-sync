# Weather icons

[Meteocons](https://github.com/basmilius/meteocons) by Bas Milius, used under the
MIT licence (see `LICENSE` in this folder).

These are the `fill` style PNGs at 512px, taken from the `v2` branch
(`production/fill/png/512`). Only the icons the dashboard maps to are vendored
here — the mapping from WMO weather codes to these filenames lives in
`dashboard_icons.py`.

To add a variant, download it from the same path and extend `WMO_ICONS`.
